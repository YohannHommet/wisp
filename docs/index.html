Engineered for Security & Speed

Peer-to-peer simplicity. Zero compromise.

Every detail of Wisp is built to guarantee wire-speed throughput without sacrificing privacy, memory safety, or cryptographic rigor.

Pure LAN P2P (Zero Cloud)

Transfers flow directly over local UDP QUIC sockets. No middleman, no telemetry, no cloud relays, no bandwidth throttling. Saturates full 1GbE and 10GbE local links.

SPAKE2 Authentication

Single-use PINs with four human-friendly words. Authenticated key exchange bound directly to TLS 1.3 channel exporters. Zero exposure to offline dictionary attacks.

BLAKE3 Cryptographic Receipts

End-to-end streaming integrity hash computed on the fly. The receiving peer verifies the entire payload and returns an authenticated cryptographic delivery receipt.

Atomic No-Clobber Storage

Files are written to temporary hidden parts and renamed atomically upon verification. Existing files are preserved automatically (file (1).ext). Interrupted transfers leave zero residue.

100% Safe Rust Core

Built with #![forbid(unsafe_code)] across all crates. Zero unsafe memory manipulation, zero Clippy warnings, audited against concurrent races and panic vectors.

True Cross-Platform

Tested continuously across Linux (x86_64, aarch64), macOS (Apple Silicon, Intel), and Windows. Single static binary with zero external runtime dependencies.

Installation & Setup

Ready in under thirty seconds.

Choose your preferred installation method. Install on both sending and receiving machines.

Install directly from this repository checkout using standard Rust toolchain:

cargo install --locked --path crates/wisp-cli
wisp --version

Requires Rust 1.88.0 or newer. Compiles optimized native binary directly into your ~/.cargo/bin path.

Linux & macOS: One-line checksum-verified installer:

curl -fsSL https://raw.githubusercontent.com/YohannHommet/wisp/develop/scripts/install.sh | bash

Windows PowerShell:

irm https://raw.githubusercontent.com/YohannHommet/wisp/develop/scripts/install.ps1 | iex

Clone and build locally with test validation:

git clone https://github.com/YohannHommet/wisp.git
cd wisp
make build
make test

Includes the 7 automated end-to-end scenarios with make demo and interactive TMUX split-screen with make demo-tmux.
